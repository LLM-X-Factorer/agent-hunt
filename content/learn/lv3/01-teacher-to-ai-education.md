# 教师 → AI Education PM 具体怎么转

这一篇不讲「为什么转」（看 [教师职业页](/professions/teacher) + [教师 Lv2 篇](/learn/lv2/teacher)），只讲**怎么一步一步转**。

## 总览：12 周路径

```
第 1-4 周：把课堂经验转成「方法论文档」
第 5-8 周：做 1 个 AI 教育 side project
第 9-12 周：投简历 + 面试 + 谈 offer
```

不需要辞职，工作日晚上 + 周末 6-8h / 周，总投入约 80h。

## 第 1-4 周：方法论工程化

教师面试 AI Education PM 最大的优势是「真正懂教学」，最大的劣势是「没法用产品 / 数据语言讲」。这 4 周就解决这个差距。

**Week 1：写「我的教学方法论」长文档**

打开 Google Docs，写下面 6 个 section：

1. 我教过的最难的概念是什么，我是怎么拆解的
2. 我设计的最好的作业 / 评估方式（一份具体例子）
3. 我发现学生学不会的 5 个最常见原因
4. 我用过的最有效的反馈机制（看眉头 / 看作业 / 课后 1v1）
5. 如果让 AI 来辅助我教学，AI 应该做什么、不应该做什么
6. 我的教学有什么 AI 不可替代的部分

每个 section 500-1000 字。**这份文档就是你的面试核心素材**，可以反复改 4 周。

**Week 2-3：用 AI 工具做教学**

每次备课 / 改作业 / 出题，**用 ChatGPT 或 Claude 跑一遍**。重点观察：

- AI 给的答案哪些可用、哪些有错
- 哪些 prompt 让 AI 输出明显更好
- AI 替你做了什么、留下了什么

记录在一份 Google Docs 里，叫「AI 工具评测笔记」。**这是你的第二份面试素材**。

**Week 4：把方法论文档 + AI 评测笔记合成「PRD」**

把上面两份合并改写成一份「AI 教育产品 PRD」：

- 用户是谁（学生 / 老师 / 家长）
- 痛点是什么（用你的真实例子）
- AI 怎么解决（用你的真实评测）
- 评估指标是什么（用学习成效 / 教师省时 / 家长满意度等）
- 风险是什么（AI 不擅长的部分）

**这份 PRD 就是面试核心 deliverable，比简历值钱 10 倍**。

## 第 5-8 周：做一个 side project

**Week 5-6：选 1 个具体场景 + 做 demo**

例如：「小学三年级数学错题本 AI 助手」
- 用 ChatGPT API（或 Coze / Dify / 飞书智能体）
- 输入：错题 + 学生答案
- 输出：错误原因诊断 + 类似题目推荐 + 讲解视频脚本

不需要写代码 — 用 [Coze](https://www.coze.cn/) 或 [Dify](https://dify.ai/) 这种 no-code Agent 平台**就够了**。

**Week 7：让真实学生用，记录效果**

找 5-10 个学生（你的学生 / 朋友的孩子）让他们用 1 周。记录：
- 用了几次 / 哪些题用了 / 哪些题没用
- 学生满意度
- 你（作为教师）的观察：学生有没有真的学会

**Week 8：把 side project 写成案例**

包含：
- 解决的是什么问题
- 产品形态（截图 + 视频）
- 真实使用数据（5-10 个学生的反馈）
- 你的反思：什么 work、什么不 work、下一版怎么改

**这个案例是你面试时讲的「具体项目」，避免说「我做过 AI 教育」却讲不出具体的事**。

## 第 9-12 周：投简历 + 面试

**Week 9：改简历**

把原来的「3 年小学数学老师」升级成「3 年教育实践 + AI 教育产品设计 + 1 个真实 side project」。
- 教师经历保留，但用「设计教学方案 / 评估学生 / 调优反馈循环」这种产品语言重写
- AI side project 单独一段，附 GitHub / Coze 链接 / 视频
- PRD 文档作为附件（求职信里附上）

**Week 10-11：投这 3 类公司**

| 优先级 | 公司 | 推荐岗位 |
|---|---|---|
| ⭐⭐⭐ | 高途、好未来、新东方、网易有道、智谱清言（智学）| AI 教育产品经理、AI 训练师、AI 内容运营 |
| ⭐⭐ | 字节（教育部门）、腾讯教育、阿里教育、百度智能云教育 | AI 教育解决方案、AI 教育 BD |
| ⭐ | 教育 AI 创业公司（少儿编程 / 学习机 / AI 助教） | AI 产品负责人、教学创新负责人 |

**Week 12：面试 + 谈 offer**

面试常见问题：
- 「为什么从老师转产品」→ 用你的方法论文档 + 评测笔记回答
- 「你有产品经验吗」→ 用 side project + PRD 回答
- 「数据分析能力」→ 用 side project 5-10 学生的真实数据回答
- 「你怎么看 AI 替代教师」→ 用你的方法论文档第 6 节回答

谈薪：教师转 AI 教育 PM 起薪范围 **18-30k**，比 K12 老师高 30-100%。

## 不要犯的 3 个错

**1. 不要先去读《产品经理入门》之类的书。** 你不是从 0 开始的产品经理，你是「带了 3 年教学经验来做产品」。直接做 side project 比看书学 frameworks 有用 10 倍。

**2. 不要追求 side project「完美」。** 5-10 个学生用 1 周就够了。重点是有真实使用数据，不是炫技。

**3. 不要海投。** 找精准 3 类公司，每个公司至少投 2 个岗位（PM + 训练师双投，看面试官引导）。

## 12 周后你应该长什么样

- 一份方法论文档（4000-6000 字）
- 一份 AI 工具评测笔记（持续维护）
- 一份 AI 教育 PRD（2000-3000 字）
- 1 个真实使用过的 side project（含 5-10 学生反馈）
- 改造后的简历 + 求职信
- 投了 15-20 家公司 + 拿到 3-5 个面试 + 1-3 个 offer

这是真实可执行的路径，不是鸡汤。**核心是 80h 时间 + 你已有的教学经验**，不是「我得先转码 + 学 Python + 考 PMP」那种漫长 detour。
