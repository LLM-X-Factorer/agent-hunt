# 销售 → AI 销售 / AI ToB BD 具体怎么转

这一篇不讲「为什么转」（看 [销售职业页](/professions/sales) + [销售 Lv2 篇](/learn/lv2/sales)），只讲**怎么一步一步转**。

**好消息**：这条路是 8 个传统职业转岗里**最容易的一条**。agent-hunt 数据：销售 + AI 100 条样本里，**43 条 pivot 到「AI 销售 / BD」簇** — 信号比任何其他职业都强。原因：销售的核心能力（行业资源 + 客户关系 + 拿单话术）**不需要重学**，只需要加 AI 工具 demo 能力和 ROI 话术。

## 总览：12 周路径

```
第 1-4 周：吃透 1-2 个 AI 产品 + 写「AI 在我行业的 ROI 话术」
第 5-8 周：做 1 个 AI ToB 解决方案案例（最值钱：你自己客户的真实场景）
第 9-12 周：投 OpenAI / Anthropic 中国 BD / 国内大模型公司行业 BD
```

不需要辞职，工作日晚上 + 周末 6-8h / 周，总投入约 80h。

## 第 1-4 周：吃透 AI 产品 + ROI 话术

销售面试 AI 销售岗最大的优势是「真懂行业 + 客户关系硬」，最大的劣势是「AI 产品没用透 + 不会用技术语言讲 ROI」。这 4 周补这个差距。

**Week 1：把 1 个 AI 产品用到「专家级」**

选 1 个最适合你目标客户的 AI 产品（**只选一个，用透**）：

| 你的目标客户 | 推荐主用产品 |
|---|---|
| 大企业 / 金融 / 制造 | ChatGPT Enterprise / Claude / 智谱 ChatGLM Enterprise |
| 中小企业 / 个人开发者 | OpenAI API + ChatGPT Plus / Claude Pro |
| 国内 SMB / 内容工作者 | 文心一言 / 通义千问 / 智谱清言 / Kimi |
| AI Agent / 工作流 | Coze / Dify / 飞书 AI / 钉钉 AI |

**每天用至少 1 小时**，做你自己的销售流程的 5 件事：
- 写客户跟进邮件
- 准备客户提案 PPT
- 做客户行业研究
- 处理 CRM 数据
- 模拟客户问答

**目标 (Week 1 末)**：能在 15 分钟内做完一个「客户行业研究 → 跟进邮件 → 提案 outline」全流程，平时要 3-4 小时。

**Week 2：用 Coze / Dify 做一个 demo Agent**

用 no-code 平台做一个「针对你目标客户场景」的 AI Agent demo：
- 客服 Agent（教育公司想要的）
- 报价生成 Agent（制造公司想要的）
- 投研报告 Agent（金融客户想要的）
- 合同审阅 Agent（律所客户想要的）

**3-5 天可以做完**，**不需要写代码**。重点是：你可以在客户会上**真打开 demo 跑给他看**，不是只看 PPT。

**Week 3：写「AI 在我行业的 ROI 话术」**

写下面 6 个 section（每个 500-1000 字）：

1. 我所在行业的 3-5 个典型客户场景（具体到岗位 + 流程）
2. 每个场景的当前痛点（成本 / 时间 / 错误率）
3. AI 在这个场景的解决方案（用什么模型 + 什么工具）
4. **具体 ROI 计算**：节省 X 小时 / 减少 Y 错误 / 提升 Z% 效率 = 多少钱
5. 哪些场景 AI 做不了 / 反而会增加风险（重要！避免过度承诺）
6. 我的客户关系网络里，哪些客户最适合做 AI 早期 case

**这份文档是面试核心素材，也是你后续做单的核心武器**。

**Week 4：写「AI ToB 销售方案模板」**

把上面的 ROI 话术合成一份「客户提案模板」：

- 客户场景诊断
- AI 解决方案
- ROI 计算 + 投入产出 timeline
- 试点方案（30-60 天 MVP）
- 风险与降级方案

**这份模板是面试时讲的「具体能交付的东西」**。

## 第 5-8 周：做 1 个真实案例

**Week 5：找 1-2 个真实客户做试点（核心一步）**

如果你现在还在职做销售：**和 1-2 个最熟的老客户聊**，告诉他们你在研究 AI 行业方案，能不能让他们做免费 / 低价试点。**90% 老客户都愿意配合**（对他们也有价值）。

试点 3 种形式（选 1 种）：

| 形式 | 客户成本 | 你的工作量 | 简历价值 |
|---|---|---|---|
| **客户某个具体流程 AI 自动化**（合同 / 报价 / 客服） | 中 | 高 | ⭐⭐⭐⭐⭐ |
| **客户内部 AI 工具培训 / Workshop** | 低 | 中 | ⭐⭐⭐⭐ |
| **客户行业 AI 调研报告交付** | 极低 | 中 | ⭐⭐⭐ |

**Week 6-7：实施 + 跟单**

- 用你 Week 2 做的 demo Agent + ROI 话术，给客户做一次正式提案
- 记录客户反馈：哪些问题问到了 / 哪些场景客户最关心 / 哪些「AI 风险」客户最担心
- 修改你的 ROI 话术 + 提案模板

**Week 8：写成销售 case 报告**

包含：
- 客户背景（行业 + 规模 + 关键人）
- 客户痛点（具体到流程）
- AI 解决方案 + ROI
- **实施效果**（客户反馈 + 实际节省 / 实际提升）
- **后续单**：试点后客户是否愿意付费扩大

**这份 case 报告是你面试时讲的「我已经跑通的具体 case」**，比任何吹牛都有说服力。

## 第 9-12 周：投简历 + 面试

**Week 9：改简历 + LinkedIn 资料**

把原来的「N 年 ToB 销售」升级成「N 年行业 ToB 销售 + 1 个真实 AI ToB 试点 case」。
- 销售业绩保留（年度回款 / 大客户清单 / 复购率）
- AI case 单独一段，附 ROI 数字 + 客户反馈
- **LinkedIn 资料英文化**（如果想投海外公司）
- 行业资源作为简历亮点（如果有 OpenAI / Anthropic 想要的行业资源比如金融 / 医疗 / 教育 / 政府）

**Week 10-11：投这 3 类公司**

| 优先级 | 公司类型 | 推荐岗位 |
|---|---|---|
| ⭐⭐⭐ | 海外 AI 公司中国 BD | OpenAI / Anthropic / Cohere / Mistral / Hugging Face → Strategic Account Executive、Sales Director（英语流利是必要） |
| ⭐⭐⭐ | 国内大模型公司行业 BD | 智谱 AI / MiniMax / Moonshot / 百川 / 月之暗面 / DeepSeek → 医疗 / 金融 / 教育 / 制造行业销售 |
| ⭐⭐ | AI SaaS / 工具销售 | Coze / Dify / 飞书 AI / 钉钉 AI / 字节 AI BD / 腾讯 AI / 阿里通义 BD → 行业解决方案经理 |

**Week 12：面试 + 谈 offer**

面试常见问题：
- 「你的行业资源是什么」→ 用客户清单 + 大客户案例回答
- 「AI 销售和传统销售有什么区别」→ 用你的 ROI 话术第 5 节回答（讲 AI 边界 + 不能过度承诺）
- 「演示一下 AI 产品」→ 用你的 Coze demo + 试点 case 实际跑给面试官看
- 「如果客户问 AI 安全风险怎么办」→ 用方法论第 5 节回答

谈薪：销售 → AI 销售岗薪资范围（**重要：销售薪资 base + 提成两块都要谈**）：

- **海外公司中国 BD**：base 25-50k + 大单提成（5-15% commission），年包 50-200 万人民币
- **国内大模型行业 BD**：base 20-40k + 提成（5-10%），年包 40-100 万
- **AI SaaS 销售**：base 15-30k + 提成（10-20%），年包 25-60 万

## 不要犯的 3 个错

**1. 不要去学技术 / 学编程**。AI 销售岗**完全不需要会写代码** — 客户买的是 ROI 不是 Python。**学 SQL / Python 是浪费 80% 时间**。

**2. 不要扔掉你的行业资源换行业**。比如你做了 5 年医疗销售 → 跳去做 AI 教育销售，**这是浪费最贵的资产**。**留在原行业做「行业 + AI 销售」是最高 ROI 的路径**。

**3. 不要海投**。AI 销售岗几乎全是 LinkedIn / 公司官网 / 内推。**找已经做 AI 销售的朋友内推 1 家 > 海投 50 家**。

## 12 周后你应该长什么样

- 1 个 AI 产品的「专家级」使用能力
- 1 个 Coze / Dify Agent demo（能在客户会上跑）
- 一份 AI ROI 话术文档（4000-6000 字）
- 1 个真实客户试点 case（含 ROI 数字 + 客户反馈）
- 改造后的简历 + LinkedIn 资料
- 投了 10-15 家公司 + 拿到 5-8 个面试 + 2-4 个 offer

**核心是 80h 时间 + 你已有的行业资源 + 客户关系**。这条路 90% 的人能成。

## 长期成长方向

- **第 1 年**：在 AI 公司做行业 BD，跑通 5-10 个真实客户
- **第 2-3 年**：升级到 Strategic Account Executive，拿到大客户拓展资源
- **第 3-5 年**：行业 BD 总监 / Sales Director → 年包可达 200-500 万
- **海外路径**：英语流利 + 国内业绩 → 转去海外公司新加坡 / 香港 BD 团队
