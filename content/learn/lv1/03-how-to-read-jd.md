# 怎么读一份 JD（拆字段教你看懂招聘信息）

打开任何一个招聘网站，每条 JD 都长得差不多：800 字密密麻麻的中文（或英文）。

**但其实你不需要全读。** 一份 JD 真正决定「这岗适不适合我」的，只有 7 个字段。掌握这套拆字段方法，你 5 秒就能从一屏 JD 列表里筛出该深读的 2-3 条。

## 字段 1：标题（10 秒判断方向）

标题告诉你**这岗属于哪个大方向**。AI 行业里高频出现的标题词：

| 标题词 | 真实含义 |
|---|---|
| **AI 工程师 / AI Engineer** | 用 LLM 拼应用，不训练模型（最大类，国内 700+ 岗位） |
| **算法工程师 / Algorithm** | 训模型 / 改 loss / 调超参，需要 ML 基础 |
| **AI 产品经理** | 设计 AI 产品流程，不写代码 |
| **AI 运营 / 训练师** | Prompt 调优、评测、内容运营 |
| **AI 销售 / BD** | ToB 大客户拓展 + AI 解决方案 |
| **大模型 / LLM** | 通常是上面几个之一的细分版 |

⚠️ 警惕**「AI 全栈工程师 / AI 高级工程师」**这种含糊标题 — 看正文才知道是工程岗还是研究岗。

## 字段 2：公司（决定职业天花板）

同样的岗位标题，在不同公司差异很大。简单分 3 类：

- **大模型公司**（智谱 / MiniMax / Moonshot / 百川 / DeepSeek）：AI 是核心业务，岗位严肃，技术深度高
- **大厂 AI 团队**（字节 / 腾讯 / 阿里 / 百度）：AI 是业务支撑，岗位多但层级细
- **传统行业 + AI 标签**（银行 / 制造 / 教育公司里的 AI 团队）：AI 是工具，业务为主导，转岗者友好

**怎么用**：你想要技术深度去前 2 类，你想用现有行业经验去第 3 类。

## 字段 3：薪资范围（看清「月薪」还是「年包」）

国内 JD 一般写「20k-40k · 13 薪」= 月薪 20-40k，年总包 26-52w。海外 JD 一般写「$120k-180k」= 年薪总包。**两者口径完全不同**，跨市场对比时换算最容易出错。

Agent Hunt 已经做了汇率换算 + 月化（÷12），所以你看到的所有薪资都是「月薪人民币口径」，能跨市场直接对比。

**实战技巧**：JD 写「20k-40k」，p25 概率拿到 **22-25k**，不是 35k。公司挂的高端值是给资深候选人或特别匹配的人，不是平均水平。

## 字段 4：学历（最容易卡的硬条件）

JD 里有 3 种常见学历写法：

1. **「本科及以上」/「Bachelor or above」** = 大专投了多半被刷
2. **「硕士及以上」** = 本科投了被刷概率 70%（除非有特别匹配项目）
3. **「学历不限」** = 真的不卡，但常出现在 SP / 销售 / 运营岗

⚠️ 注意：**国内 AI 算法 / 大模型公司**（智谱 / Moonshot 等）的算法岗位 70% 默认要硕博，哪怕 JD 写「本科及以上」— 这是潜规则。AI 工程师（应用层）反而本科可投。

## 字段 5：经验年限（区分「真硬」和「软建议」）

「3-5 年经验」在 JD 里的真实含义：

- **「3 年以上」** = 经常 2 年也面，看你简历项目厚度
- **「5 年以上」** = 4 年大概率投了不回，6-8 年最佳
- **「不限」/「应届可投」** = 真的友好，但岗位往往薪资偏低

**实战技巧**：差 1 年的，简历投得过；差 2 年以上的，除非有特别匹配的项目，多半被自动筛掉。

## 字段 6：技能要求（**重点**，分 required vs preferred）

这是最重要的字段，下一篇 [蛋糕列描述：required vs preferred](/learn/lv1/required-vs-preferred) 专门讲。简单说：

- **「掌握 / 熟练 / 精通 / 必须」** = 硬性要求（不会就基本被刷）
- **「了解 / 熟悉 / 有 X 优先」** = 加分项（不会也能投）

**怎么用**：核对 required 列表，至少 80% 能 hit 上再投，否则投了浪费时间。

## 字段 7：工作内容（判断是不是你愿意做的事）

很多人忽视这个字段，直接对比薪资就投 — 这是大坑。

「AI Agent 工程师」可能是：
- 设计多 Agent 协作流（架构师式工作）
- 接 LangChain API 拼业务（CRUD 式工作）
- 标注训练数据 + 调 Prompt（运营式工作）

**同样的标题，工作内容差 10 倍**。读 JD 里「岗位职责」section 至少 30 秒，确认日常工作内容你真的愿意做。

## 实战：5 秒筛 JD 的流程

打开一条 JD，按这个顺序扫：

1. 标题 → 方向对不对（不对就关）
2. 公司 → 你想去这个类型吗（不想就关）
3. 学历 + 经验 → 你够格吗（不够就关）
4. 薪资范围 → p25 水平你能接受吗（不能就关）
5. Required 技能 → 你 hit 80% 吗（不 hit 就关）
6. 工作内容 → 你愿意做吗（不愿意就关）

**通过这 6 关，剩下 5-10% 的 JD 才值得深读 + 投递**。
